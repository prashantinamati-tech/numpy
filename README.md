# NumPy Fundamentals: Core Concepts & Array Operations

This repository contains introductory notebooks and code snippets focused on **NumPy (Numerical Python)**, the core foundational library for scientific computing, data manipulation, and machine learning in Python[cite: 1].

---

## 📌 Features & Key Concepts Covered

- **Array Creation & Types**: Initializing 1D and multi-dimensional arrays, type inference, array checking (`.shape`, `type()`), and initializing populated matrices like `np.zeros()`[cite: 1].
- **Array Indexing & Slicing**: Subsetting 1D arrays using standard slicing syntax (`arr[0:4]`)[cite: 1].
- **Vectorized Arithmetic**: Fast element-wise mathematical operations across arrays without explicit loops[cite: 1].
- **Boolean Indexing**: Filtering arrays dynamically using condition masks (e.g., `arr[arr > 3]`)[cite: 1].
- **Reshaping & Manipulation**: Transforming array dimensions using `np.arange()` and `.reshape()`[cite: 1].
- **Ecosystem Integration**: Seamless integration capabilities with downstream data science libraries like Pandas, Matplotlib, and Scikit-Learn[cite: 1].
